# Motion Midway 🎪

เกมป๊อปลูกโป่งด้วยการขยับตัวหน้ากล้อง — เขียนด้วย HTML/CSS/JavaScript ล้วน ๆ ไม่ต้อง build ไม่ต้องติดตั้งไลบรารีใด ๆ

## วิธีรันใน VS Code

กล้อง (`getUserMedia`) ใช้งานได้เฉพาะบน **secure context** (`https://` หรือ `http://localhost`) เท่านั้น การดับเบิลคลิกเปิดไฟล์ตรง ๆ (`file://`) จะถูกเบราว์เซอร์บล็อกกล้อง จึงต้องรันผ่านเซิร์ฟเวอร์เล็ก ๆ ดังนี้:

**วิธีที่ 1 — ส่วนขยาย Live Server (แนะนำ)**
1. เปิดโฟลเดอร์นี้ใน VS Code
2. ติดตั้งส่วนขยาย **"Live Server"** (โดย Ritwick Dey) จาก Extensions
3. คลิกขวาที่ `index.html` → เลือก **"Open with Live Server"**
4. เบราว์เซอร์จะเปิดที่ `http://127.0.0.1:5500` — กด "เริ่มเกม" แล้วอนุญาตสิทธิ์กล้อง

**วิธีที่ 2 — เทอร์มินัลในตัว VS Code**
```bash
cd motion-midway
python3 -m http.server 8000
```
แล้วเปิด `http://localhost:8000` ในเบราว์เซอร์

## วิธีเล่น
- อนุญาตให้เว็บไซต์ใช้กล้อง
- ยืนให้ตัวเองอยู่ในเฟรมกล้อง
- ลูกโป่งจะลอยขึ้นจากด้านล่าง — โบกมือหรือขยับตัวให้ไปโดนลูกโป่งเพื่อป๊อป
- ลูกโป่งลูกเล็กให้แต้มเยอะกว่าลูกใหญ่ แต่ลอยเร็วกว่า
- มีเวลา 60 วินาที เก็บ "ตั๋ว" (แต้ม) ให้ได้เยอะที่สุด สถิติสูงสุดจะถูกบันทึกไว้ในเบราว์เซอร์

## หลักการทำงาน
เกมจับภาพจากกล้องมาลดขนาดเหลือกริดเล็ก ๆ (20×15) แล้วเทียบความต่างของแต่ละพิกเซลระหว่างเฟรมปัจจุบันกับเฟรมก่อนหน้า (frame differencing) จุดไหนต่างเกินค่ากำหนดถือว่ามีการเคลื่อนไหว — ถ้าตำแหน่งลูกโป่งอยู่ในบริเวณที่มีการเคลื่อนไหวมากพอ ลูกโป่งจะแตก ไม่มีการส่งภาพจากกล้องออกจากเครื่องเลย ทุกอย่างประมวลผลในเบราว์เซอร์ทั้งหมด

## ไฟล์ในโปรเจกต์
- `index.html` — โครงหน้าเกม
- `style.css` — ธีมงานคาร์นิวัล/งานวัด
- `game.js` — ลอจิกเกมทั้งหมด (กล้อง, จับการเคลื่อนไหว, ลูกโป่ง, คะแนน, เวลา)
